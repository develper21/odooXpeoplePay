# PeoplePay360 Project Context

PeoplePay360 is an HR and payroll operations platform. The Employee record will eventually connect contracts, schedules, attendance, time off, salary structures, salary rules, payruns, payslips, payments, and reporting.

## Technology

- Next.js App Router with TypeScript
- Tailwind CSS v4 and local shadcn/ui-compatible primitives
- TanStack Query provider for the future API-backed data layer
- React Hook Form and Zod for form boundaries
- Recharts for dashboard visualizations
- Lucide React for icons

## Product Direction

The interface uses a dense, dark enterprise SaaS visual language: compact bordered surfaces, blue primary actions, semantic status colors, responsive navigation, and information-dense dashboard composition.

Sprint 1 is foundation-only. Business workflows and backend integration belong to later sprints.
